# 已知限制

这一页列出语言里有意不做的部分，还有检查在什么时候才下结论。

这些都不是漏掉的功能。

写程序之前看一眼，省得写到一半才发现。

## 有意不提供的能力

| 范围 | 不提供 | 替代写法 |
| --- | --- | --- |
| 函数 | 闭包与匿名函数 | 具名函数加一个显式 `class` 装上下文 |
| 函数 | 多返回值 | 用 `struct` 或 `class` 把几样装在一起 |
| 泛型 | 约束（`where`／`extends`） | 类型参数不设条件，用到什么由实参决定 |
| 泛型 | `interface` 方法带类型参数、`type` 别名带尖括号 | 改用具名类型 |
| 容器 | `list.contains`、`dict.items`、`hashset.is_subset` | `xs.index_of(v) >= 0` 等现有成员 |
| 文本 | Unicode 大小写表；大小写与空白只认六个 ASCII 字节 | 需要按 Unicode 处理时自己写 |
| 数值 | 双曲函数、`atan2`、`hypot` | 用现有的三角与幂函数组合 |
| 时间 | 时区数据库、按日历换算时区 | `time.utc_offset()` 给一个分钟数，自己加减 |
| 文件 | POSIX 权限位、移动文件、按行读出 | `is_readonly` 问 Windows 只读标记；`rename` 在同卷内移动 |
| 正则 | `{m,n}`、非贪婪量词、`\b`／`\B`、反向引用、`(?...)`、捕获组与 `$1` 替换 | 只有 `*`、`+`、`?` 与字符组；要这些写法就自己拆开处理 |
| 网络 | UDP、原始套接字、按行读写、服务端并发、锁与条件变量 | TCP 加 `bytes`；线程之间只交一次值 |
| HTTP | 分块接收、自定义根证书、异步与定时、用户名密码与百分号还原 | 用现有同步请求；超时用毫秒参数 |
| 进程 | 读取子进程输出、换目录启动 | 只有启动、等待、结束 |
| 线程 | 取消、等待多个、共享可变内存 | 每条线程交进一个值、等一个返回值 |
| 包 | 版本范围、锁文件、`install`／`publish` 命令 | 版本写死在 `nf.json` 里，包以源码分发 |

## 检查的边界

下面两条不是“不提供功能”，而是检查在什么时候才下结论。

- **模板的字段与方法体用到才检查。** 带类型参数的模板在声明处只查参数名是否合法、是否重名。字段里写错的类型、方法体里的错误，要等某一只实例生成时才报。编译器得先知道那个参数名是哪一种形状。用到哪一只就查哪一只。
- **归属判定在编译期，运行期有一道接管。** 同一实参表里既借出元素、又覆盖容器，检查阶段能看穿的当场拒绝。跨包、方法转发与局部别名这类写法，摘要看不到，在归还那一步由运行期借用表查出，抛 10097 号。借用表有 64 个位置，超出时抛 10098 号。这是资源上限，不是语言规则的违反。

## 其他边界

- 文本在容器位置、`struct` 与 `class` 字段里这一版不归还。共享那一份的持有者无法唯一确定，宁可留着，也不冒重复释放的风险。反复往里塞文本的程序会持续增长，这是已知的行为。
- 宽字符转 UTF-8 的落点是每条线程一块 64 KB 的缓冲。变量名、变量值或当前目录长到装不下时按宽字符截断后返回，不抛错。
- `file.list_names_tree` 与 `file.remove_tree` 遍历到第 64 层停止；更深的内容前者不返回，后者不删除。
