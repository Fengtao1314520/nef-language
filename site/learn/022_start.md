# 应用与入口

这一课运行第一个 Nef 程序，并且回答两个问题：程序从哪里开始执行，一条语句在哪里结束。

## 创建第一个程序

新建一个文件，命名为 `hello.nf`，写入以下内容：

```nf
// 第一个程序
console.print("你好，nef")
console.print("1 + 1 =", 1 + 1)
```

在终端中运行：

```text
nf hello.nf
```

输出：

```text
你好，nef
1 + 1 = 2
```

`console.print` 把内容输出到终端。多个参数之间自动用空格分隔；表达式先求值再输出。整数、文本和布尔值都可以直接传入，不需要先转换为文本。

## 程序的执行顺序

程序的执行从文件第一行开始，按顺序逐行进行。下面的程序包含三行有效语句：

```nf
let a:int = 1
let b:int = 2
console.print(a + b)      // 3
```

第一行把值 `1` 绑定到名称 `a`，第二行把值 `2` 绑定到名称 `b`，第三行计算 `a + b` 并输出结果。

书写顺序就是执行顺序。没有 `main` 函数，也没有需要先执行的初始化代码。

> 注意：`let` 后面必须写类型标注。类型标注是语法的一部分，不是注释。类型标注的完整规则见[变量与类型标注](/learn/023_values)。

## 语句的结束位置

行尾就是一条语句的结束，不需要写分号。同一行书写多条语句时用分号分隔，本指南的示例一律一行写一条语句。

```nf-frag
let a:int = 1; let b:int = 2
```

## 注释

注释有两种形式：一种是 `//` 写到行末，另一种是 `/* ... */`，后者可以跨越多行。

```nf-frag
// 这一行不算代码

/* 这一段都不算代码，
   可以跨几行 */
```

块注释不能嵌套，遇到第一个 `*/` 就结束整段注释。

写在声明上面的注释会出现在编辑器里。鼠标停在声明的名称上，签名下面依次显示三段：中文说明、以 `en:` 开头的英文说明、以 `例：` 开头的示例，示例显示成一个 nf 代码块。这两个前缀只用来分段，屏幕上不出现。

```nf
// 把这一个数加两遍。
// en: Adds the same number twice.
// 例：
// console.print(twice(21))
method twice(n: int): int {
    return n + n
}
```

编译器会忽略注释：注释在语言里没有语义，词法阶段整段丢弃，写与不写都不改变程序的运行结果。

> 注意：字符串字面量中的 `//` 不是注释。`"http://a"` 里的两个斜杠就是两个字符，词法分析不会进入字符串内部寻找注释标记。

## 练习

向 `hello.nf` 追加一行代码，让它输出 `3 × 7 = 21`。

按下面的格式书写：引号中放要输出的文本，逗号之后放表达式。

```nf-frag
console.print("要印的文字", 1 + 1)
```

乘法运算符是 `*`。`console.print` 会在相邻参数之间自动插入一个空格，字符串末尾不需要再写空格；如果多写一个空格，输出中就会出现两个空格。
