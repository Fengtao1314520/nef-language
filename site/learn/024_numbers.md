# 数字与小数

这一节处理一笔金额计算：单价 12.5，数量 3，要算出总价，再把它分给两个人。

这里第一个要解决的不是运算符，而是类型：`37.5 / 2` 与 `36 / 2` 各属于哪一种数值类型，除不尽时剩下的部分去了哪里。Nef 只提供 `int` 与 `float` 两种数值类型，剩下的规则都围绕两者的区别展开。

## 两种数值类型

| 类型 | 存的值 | 字面量 |
| --- | --- | --- |
| `int` | 整数，−9223372036854775808 到 9223372036854775807 | `42`、`-7`、`1_000_000`、`0xFF` |
| `float` | 小数，64 位双精度 | `3.14`、`-0.5`、`1_000.25` |

整数没有宽度可选：不分 8 位、16 位、32 位，也不分有符号与无符号。小数只有一种，即 64 位 IEEE 754 双精度。

取值范围最小的整数写不出字面量。`-9223372036854775808` 里，词法分析先读到的是 `9223372036854775808`，当场报 `数字 9223372036854775808 存不下`，减号还没来得及参与。

要得到这个数，就从零开始减：`0 - 9223372036854775807 - 1`。

两种类型之间不自动转换。

数字中间可以用 `_` 分组，便于阅读较长的数；十六进制以 `0x` 开头，没有二进制和八进制字面量。

`0xFF` 与 `255` 是同一个值的不同写法。

## 没有科学计数法

`1e9` 会被读成数字 `1` 后面紧跟一个名称 `e9`，编译器报“数字后面直接跟了名字”。

需要较大的数就完整写出：`1_000_000_000.0`。

## 整数除法与取余

`int` 的 `/` 是商向零截断的除法，`%` 给出余数，余数的符号跟随左侧操作数：

```nf
console.print(7 / 2, 7 % 2)
console.print(-7 / 2, -7 % 2)
```

```text
3 1
-3 -1
```

第一行是 `3` 和 `1`：7 除以 2 截断为 3，剩下的 1 由 `%` 给出。第二行两个结果都是负数，因为向零截断把 `-3.5` 取为 `-3`，而余数的符号跟随左侧操作数。

两条规则合起来恒满足 `(a / b) * b + a % b == a`。

如果记不清 `-7 % 2` 是 `1` 还是 `-1`，把数值代入这条式子即可：`-7 / 2` 是 `-3`，`-3 * 2` 是 `-6`，要得到 `-7` 就只能再加 `-1`。

`float` 同样支持 `+ - * /`，`%` 按 fmod（C 标准库里的小数取余规则）计算，符号也跟随左侧操作数。两侧类型必须一致：

```nf
console.print(7.5 % 2.0)      // 1.5
```

写成 `7.5 % 2` 会被拒绝：`%` 两侧必须是同一类型，这里是 `float` 与 `int`。不存在隐式转换。

## 类型转换要写出来

`int` 与 `float` 之间不自动转换，需要转换就使用 `as`：

```nf
let price:float = 12.5
let pieces:int = 3

let total:float = price * (pieces as float)
console.print(total)          // 37.5
```

去掉 `pieces as float`，编译器的提示是 `* 两边必须是同一类型：float 与 int`。`as` 是唯一的类型转换记号。

`float` 转换为 `int` 是向零截断，小数部分直接丢弃：

```nf
console.print(3.9 as int, -3.9 as int)
```

```text
3 -3
```

> 注意：向零截断不等于向下取整。`math.floor(-3.9)` 得 `-4`，而 `-3.9 as int` 得 `-3`，两者经常被混为一谈。

## 整数溢出与浮点精度

整数的加、减、乘、除如果结果超出范围，不会回绕，而是在运行时抛出 10021 号错误（`整数运算溢出`），可以用 `catch` 捕获。字面量本身就超出范围时，编译器直接报错，程序不会进入运行阶段（移位不适用这一条，见下面的“位运算”）：

```nf-bad
let big:int = 9223372036854775808    // 报：数字 9223372036854775808 存不下
```

`float` 完全遵循 IEEE 754：上溢得到无穷，下溢得到 `0`，`0.0 / 0.0` 得到 `NaN`，这些都不报错。`NaN` 不等于自身，且 `NaN` 参与大小比较时结果一律为假。

整数除以 `0` 会抛出错误，不会返回 `NaN`，也不会返回无穷。

> 注意：`console.print` 输出小数时，选择能够完整还原原值的最短写法，并且始终带上小数点。`3.0` 输出为 `3.0`，`0.1 + 0.2` 输出为 `0.30000000000000004`。需要展示整齐的数字时，请在输出之前自行取整。

## 位运算

`int` 和 `byte` 支持 `& | ^ ~ << >>`，其他类型不支持：

```nf
let shifted:int = 1 << 4
console.print(shifted, shifted | 2, shifted & 20, shifted >> 1)
```

```text
16 18 16 8
```

`1 << 4` 得到 16。`16 | 2` 把值为 2 的那一位补上，得到 18；`16 & 20` 保留两侧同为 1 的位，得到 16；`16 >> 1` 右移一位，得到 8。

移位量只接受 `byte` 类型。写成常量时可以省掉类型标注，`1 << 4` 能通过检查；写成变量名时，它的类型必须是 `byte`，`let s:int = 70` 之后写 `1 << s` 报 `移位量只能写 byte 或一个 0～255 的整数，这里是 int`。

越界分两种情况判断。以常量形式写出的移位量越界时在编译期报错：`int` 越出 `0` ~ `63`、`byte` 越出 `0` ~ `7`。

计算得到的移位量要到运行期判断，超过左操作数可以移位的位数就抛出 10021 号错误（`整数运算溢出`）。`let s:byte = 70` 之后的 `1 << s` 属于运行期判断，不会静默丢弃高位。`>>` 对 `int` 是算术右移，符号位随之移动，因此 `-16 >> 2` 得到 `-4`。

`16 & 20` 的结果是 `16` 而不是 `0`：`16` 是 `10000`，`20` 是 `10100`，两个数在值为 16 的那一位上都是 `1`，按位与保留的就是这一位。要得到 `0` 需要写成 `16 & 3`（`10000` 与 `00011`，没有任何一位重合）。

`byte` 表示一个字节，取值 0 到 255。

两个 `byte` 相加、相减、相乘或移位，结果类型是 `int`：`let a:byte = 200` 之后写 `a + a`，得到 `400`。这个 `400` 无法赋给 `byte` 类型的名称，`let b:byte = a + a` 是编译错误。

要转换回一个字节就显式写 `as byte`，值不在 0~255 内时在运行时抛出 10013 号错误（`超出了 byte 的值域`）。

对 `255` 再执行 `++`，同样抛出 10013 号错误，不会输出 `256`。完整的取值范围见[类型一览](/reference/035_types)。
