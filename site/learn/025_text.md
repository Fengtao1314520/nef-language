# 文本与码点

`length("中文abc")` 给出 5 还是 8？`"共 {n} 件"` 会不会把 `{n}` 替换成变量的值？两个问题的答案来自同一条规则：文本是不可变的码点序列，存储采用 UTF-8 字节。

## 两种字面量语法

文本的类型是 `string`，单个字符的类型是 `unicode`：一个 Unicode 码点，占 4 字节。

```nf
let sign:string = "站台"
let first:unicode = '站'

console.print(sign, first)      // 站台 站
```

双引号表示文本，单引号表示一个码点，两者不能互相替代。单引号内必须恰好一个码点，写入两个就是错误。

## 长度与下标都按码点计算

`length(s)` 返回码点个数，不是字节数。`s[i]` 取第 `i` 个码点，下标从 `0` 开始：

```nf
let word:string = "中文abc"

console.print(length(word))     // 5
console.print(word[0], word[3]) // 中 b
```

`word[3]` 是 `b` 不是 `a`：`中`、`文`、`a`、`b`、`c` 共五个码点，从 `0` 数起，第 3 个码点是 `b`。

一个汉字在 UTF-8 中占三个字节，但只算一个码点，所以长度是 5 而不是 8。不少语言里 `length` 给出的数字与目测的字数不一致，这里统计长度和使用下标用的是同一个单位：码点。

这种存储还决定了两个操作的开销。文本按 UTF-8 字节存放，头部另外保存码点个数，所以 `length` 只是读取一个已经保存的数字，开销很小；`word[i]` 需要从第 0 个字节扫描到第 i 个码点的起始位置，代价是 `O(n)`（n 是码点个数）。

> 注意：需要频繁随机访问字符时，先把字符逐个存入 `list<string>`（每个元素一个码点），再按下标取用。这个容器保存的是定宽句柄（每个元素占用同样宽度的引用），取一个元素不需要遍历字节。

下标越界不会返回空字符，而是在运行时抛出错误。

## 文本的不可变性

`+` 拼接产生的是一段新文本，原内容不变。需要“修改一个字符”时只能拼接出一段新文本：

```nf
let a:string = "书包"
let b:string = a + "和伞"

console.print(a, b)             // 书包 书包和伞
```

`a` 仍是原来的两个字，`b` 是新拼接的结果。

`s[0] = 'X'` 是编译错误。

不可变带来两条可以依靠的性质。把文本传给一个函数，不需要询问函数是否会修改内容，因为文本无法修改。两个文本比较相等时，也不需要担心“比较进行到一半时其中一边被改写”。

拼接新文本的成本按文本长度计算：`a = a + "！"` 每执行一次就完整复制一遍。

## 按码点顺序比较

`==`、`!=` 逐码点比较内容。`<`、`<=`、`>`、`>=` 按码点先后顺序比较，与中文按笔画排列的顺序无关：

```nf
console.print("苹果" == "苹果", "乙" < "甲", "Z" < "a")
```

```text
true true true
```

`"Z" < "a"` 为真，因为大写字母的码点小于小写字母。

`"乙" < "甲"` 同样为真：乙是 `U+4E59`，甲是 `U+7532`。按笔画或按拼音排序，甲都应排在乙之前；按码点排序则乙在前。**顺序由 Unicode 码点表决定**，无法更改；反过来写 `"甲" < "乙"`，就得到 `false`。

需要按笔画或者拼音排列中文时没有现成的支持：排序键要按业务规则自行计算，例如先把文本转换成拼音或者笔画数再比较。

## 转义形式只有五种

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\"` | 一个双引号 |
| `\\` | 一个反斜杠 |
| `\uXXXX` | 码点为 `XXXX` 的字符，四位十六进制 |

书写这五种之外的转义（例如 `\z`）是编译错误；`\u` 之后不足四位或者不是十六进制同样是编译错误。文本中需要单引号时直接书写，不需要转义。

没有 `\r` 这个转义形式。判断回车只能写 `"\u000D"`，不过通常不需要，`trim()` 会把行尾的回车作为空白一并去掉。

## 不支持字符串插值

`"共 {n} 件"` 中的 `{n}` 不会被替换，花括号和中间的字母 n 这三个字符就是字面内容。

拼接一律使用 `+`，需要把数字并入文本就显式转换：

```nf
let n:int = 3

console.print("共 " + number.to_string(n) + " 件")   // 共 3 件
```

`number.to_string(value)` 把值转换为文本，反向转换是 `text.to_int(s)`。后者是解析，不是类型转换，因此不使用 `as`；无法解析为数字时会抛出错误。更多文本操作见[文本处理](/stdlib/046_text)。

## 遍历文本

文本可以直接遍历，每一轮给出一个码点：

```nf
for (ch:unicode in "便条") {
    console.print(ch)
}
```

```text
便
条
```

遍历得到的 `ch` 是只读借用，出了这一轮就失效；该规则在[值的所有权](/learn/026_ownership)中完整说明。

## 练习

`console.print("中文"[0] == '中')` 输出什么？先写出结论，再运行验证。

判断时注意两点：下标返回的是什么类型，单引号括起来的又是什么类型。

接着处理本节开头出现的 `"中文abc"`：取出它的前两个字符作为标签。`s[0]` 返回的是码点而不是文本，`s[0] + "x"` 会被拒绝，可以尝试 `s.slice(0, 2)`。

## 本节要点

计数按码点，存储按 UTF-8 字节；文本不可变，任何修改都会得到一段新文本；单个字符属于 `unicode` 类型，与 `string` 不能互相替代。
