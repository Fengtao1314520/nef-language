# 语法速查

全部记号、关键字、保留名和运算顺序，用一页列出。写代码时可以随时查阅这一页，各项规则的完整边界在[语法参考总览](/reference/033_index)里。

## 声明

从变量声明到跨文件共享，一共十五种写法：

| 写法 | 意思 |
| --- | --- |
| `let x:int = 1` | 可以再次赋值的变量 |
| `const limit:int = 100` | 不可修改的值，只能是值类型 |
| `let items:list<string> = []` | `list`。为空时由左侧的类型标注确定元素类型 |
| `let d:dict<string, int> = {}` | 键到值的映射 |
| `let s:hashset<int> = {}` | 去重集合 |
| `method add(a:int, b:int):int { return a + b }` | 函数；写在 `class` 里就是方法 |
| `method show(m:string) { }` | 不写返回类型表示不返回值 |
| `struct Point { x:int  y:int }` | 一组值，赋值时整份拷贝 |
| `class Circle { r:float  method area():float { return 3.14159 * r * r } }` | 字段与方法组合，用 `new` 创建 |
| `interface Shape { perim():float }` | 方法声明；接口体内的声明前面不写 `method` |
| `enum Day { mon, tue, wed }` | 只保存整数，默认从 0 开始递增 |
| `type Names = list<string>` | 给一个已有的类型另起一个名字，不是一种新类型 |
| `import { helper } from "./util.nf"` | 引用其他文件导出的名称 |
| `import greet from "libs/greet"` | 引入一个包：整个包绑定一个名称，访问其中的成员写 `greet.make()` |
| `export method helper(n:int):int { }` | 把紧随其后的名称对外导出 |
| `export shared log:list<string> = []` | 跨文件共用一份可变的容器 |
| `method total(ref xs:list<string>):int { }` | 参数前面写 `ref`：那一个位置只是借来使用，不接管持有关系，调用方的名称不失效 |

容易忽略的两处：`interface` 里的方法声明不写 `method`，写了是编译错误；`export shared` 必须成对，单独一个 `shared` 不成立。

## 运算符

运算符共十类、23 个记号。`as`、`is` 是关键字，`-` 在词法表里只登记一次（减法与取负是同一个记号）。

词法表一共 33 条，包含这 23 个运算记号和 10 个标点：`(`、`)`、`{`、`}`、`[`、`]`、`:`、`,`、`;`、`.`。

| 类别 | 记号 | 适用范围 |
| --- | --- | --- |
| 算术 | `+ - * / %` | `int`、`float`、`byte`，两侧必须是同一类型；两个 `byte` 的运算结果是 `int`；`+` 还可以拼接 `string` |
| 取负 | `-x` | `int`、`float`；`byte` 没有负数范围，取负是编译错误，需要负数就先 `as int` |
| 判等 | `== !=` | 两侧必须是同一类型；`==`、`!=` 还用于判空。文本逐码点比较，`struct` 逐字段比较，`class`、装箱值与容器比较的是对象身份：两个内容相同的容器不相等 |
| 比大小 | `< <= > >=` | 只用于 `int`、`float`、`byte`、`unicode`、`string`，两侧必须是同一类型。`class`、装箱值、容器、`enum`、`boolean` 都不支持：引用类型只能比较内存地址，地址的先后随分配次序变化；`enum` 与 `boolean` 无法定义先后顺序 |
| 逻辑 | `! && \|\|` | 只用于 `boolean`，`&&`、`\|\|` 短路 |
| 位 | `& \| ^ ~ << >>` | 只用于 `int`、`byte`；`byte` 的运算结果是 `int`；移位量只接受 `byte`（写成常量时可以省略）。越界时，写成常量的移位量在编译期报错，计算得到的移位量抛出 10021 号错误 |
| 换类型 | `as` | 数字互转、装箱与拆箱；`enum` 只能 `as int` 取出对应的整数，方向单向 |
| 问类型 | `is` | 查询装箱值中装的是不是某个类型，返回 `boolean` |
| 自增自减 | `++ --` | 只能自成一条语句，用于 `int`、`float`、`byte`；`const` 的名称不允许；`int` 到顶再加一抛出 10021 号错误，`byte` 越出 0 到 255 抛出 10013 号错误 |
| 赋值 | `=` | 只能出现在语句里，不是一种值 |

没有复合赋值：`+=`、`-=`、`*=` 都不支持，要写完整的 `total = total + 1`。`=` 也不是表达式，`while ((n = f()) != 0)` 无法通过语法检查。

## 语句

| 写法 | 意思 |
| --- | --- |
| `if (x > 0) { } else if (x == 0) { } else { }` | 分支，条件位置只接受 `boolean` |
| `while (n > 0) { }` | 条件循环 |
| `for (i:int in 0 until 10) { }` | 计数：从 0 到 9，一共十次，右端不包含 |
| `for (name:string in items) { }` | 遍历：`list` 交出元素、`dict` 交出键、`string` 交出码点 |
| `switch (d) { Day.mon { } Day.tue, Day.wed { } default { } }` | 按值分派，一个分支可以并列书写几个标签 |
| `break`、`continue` | 只能出现在循环里 |
| `try { } catch (code, msg) { }` | 接收抛出的错误，没有 `finally` |
| `throw (100, "路径不能是空的")` | 抛出错误，永远是一个错误码加一条消息 |
| `exit (100, "要给我一个路径")` | 当场结束整个程序 |
| `return`、`return 值` | 返回结果；声明了返回类型的函数，每条路径都要返回 |

`switch` 的分支不会贯穿到下一个，不需要另外写跳出语句。用 `enum` 判定时成员必须列全，漏掉一个又没写 `default` 是编译错误：给枚举添加了新成员却没有改到的分支，编译器会逐处报出。

## 字面量

| 写法 | 含义 |
| --- | --- |
| `42` `-7` `1_000_000` `0xFF` | `int` |
| `3.14` `-0.5` `1_000.25` | `float` |
| `200` `0x1F` | 出现在需要 `byte` 的位置上时按 `byte` 识别，超出 0 到 255 报错；`300 as byte` 同样在编译期报错 |
| `"文本"` `""` | `string`，`""` 是空文本 |
| `'中'` `'\u4e2d'` | 一个码点 |
| `true` `false` `null` | 真、假；第三种表示引用没有指向任何值 |
| `["甲", "乙"]` `[]` | `list` |
| `{"a": 1}` | `dict` |
| `{1, 2, 3}` | `hashset` |
| `Point { x: 1, y: 2 }` | `struct` 的值，字段必须列全 |
| `new Circle(r: 2.0)` | `class` 的对象；不写初值时全部取默认值 |

`int` 的字面量只写正数的形式，最大值是 `9223372036854775807`。

字面量的最小值无法直接写出：`-9223372036854775808` 中词法先读取到的是 `9223372036854775808`，当场报 `数字 9223372036854775808 存不下`，报错发生在减号参与之前。

要得到这个数，就从零开始减：`0 - 9223372036854775807 - 1`。

没有科学计数法。`1e9` 会被读成数字 `1` 后面跟一个名称 `e9`，编译器报“数字后面直接跟了名字”。

也没有八进制。`0644` 当场报错，编译器不会把它按十进制的 `644` 悄悄收下。在这类写法差异里，字面量的值被悄悄改动是后果最严重的一种。

## 运算顺序

优先级从高到低一共十二档，同一档优先级相同，全部从左向右结合：

| 档 | 记号 |
| --- | --- |
| 后缀 | `a(...)`、`a[...]`、`a.b`、`as` |
| 一元 | `-a`、`!a`、`~a` |
| 乘除 | `*`、`/`、`%` |
| 加减 | `+`、`-` |
| 移位 | `<<`、`>>` |
| 按位与 | `&` |
| 按位异或 | `^` |
| 按位或 | `\|` |
| 比较 | `<`、`<=`、`>`、`>=` |
| 判等与问类型 | `==`、`!=`、`is` |
| 逻辑与 | `&&` |
| 逻辑或 | `\|\|` |
| 赋值 | `=`（它是语句，不参与运算顺序） |

`&`、`^`、`|` 各成一档，`&` 的优先级最高：`4 | 2 & 1` 读作 `4 | (2 & 1)`，得 `4`。这三档的优先级又都高于判等：`3 & 1 == 1` 读作 `(3 & 1) == 1`，得 `true`。

`as` 与访问成员、取下标、调用同在一档里，从左向右依次结合：`o as C.x` 就是 `(o as C).x`，括号可以省略。

`as` 的优先级也高于乘除：`2 * 3 as float` 读作 `2 * (3 as float)`，两侧成了 `int` 与 `float`，检查不通过。需要转换乘积就写 `(2 * 3) as float`。

不确定优先级时加括号，括号不影响运行速度。

## 注释

```nf-frag
// 到行尾

/* 中间这些都不算代码，可以跨行；
   块注释不能套在块注释里 */
```

字符串中的 `//` 不算注释，`"http://a"` 里的两条斜杠就是两个字符。

## 名字的写法

名称只能用 ASCII：开头是 `_`、`$` 或者大小写英文字母，其余位置还可以使用数字，以及开头允许的这三种字符。`$total`、`_tmp`、`a1_b$c` 都是合法的名称。

中文不能用作名称，一个字符都不行。`let 中:int = 1` 在词法阶段就被拒绝，报 `标识符不许含非 ASCII 字符：看到 "中"`。汉字出现在英文名中间同样不行：`let ab中:int = 1` 报 `标识符不许含非 ASCII 字符：ab中`。

其余非 ASCII 字符（希腊字母、货币符号这类）报的是 `认不出的字符 "α"`。这两类错误都到不了语法分析阶段。

中文只出现在文本和注释里，不用于名称。

## 保留名字

34 个关键字，加上 33 个内建名称，一共 67 个词不能用作变量名、字段名、函数名和类型名：

| 类别 | 名单 |
| --- | --- |
| 关键字 | `let` `const` `method` `struct` `class` `interface` `enum` `type` `import` `export` `shared` `ref` `base` `this` `new` `return` `as` `is` `throw` `try` `catch` `if` `else` `while` `for` `in` `until` `switch` `default` `break` `continue` `true` `false` `null` |
| 内建类型 | `boolean` `int` `float` `byte` `unicode` `string` `object` |
| 容器 | `list` `dict` `hashset` |
| 内建 `struct` | `Calendar` `Response` |
| 内建引用类型 | `Json` `bytes` `Socket` `Listener` `Process` |
| 内建函数 | `length` `exit` |
| 标准库组名 | `console` `text` `number` `math` `time` `file` `path` `environment` `regular_expression` `json` `bytes` `net` `http` `process` |
| 入口预置 | `args` |

`bytes` 同时是类型名与组名：`let b:bytes = bytes.new(4)` 中前一个是类型、后一个是组，名单上只登记一次。`process` 与 `Process` 是两个不同的名称，前者是组名、后者是类型名（[进程](/stdlib/053_process)）。

`add`、`remove`、`contains` 不在上面的保留名字表里：它们只是容器的方法，自定义的 `class` 中可以照常使用这三个名称。

## 未提供的写法

从其他语言转过来的开发者容易写成下面这些形式。表中左列是其他语言里的写法，右列是 Nef 要求的写法：

| 其他语言里的写法 | Nef 中的写法 |
| --- | --- |
| `T?` 可选类型 | 只有引用类型能为 `null`，判空写 `x != null` |
| `void` | 不写返回类型就是不返回值 |
| `main` 函数 | 文件顶层就是入口 |
| `+=`、`-=` 等复合赋值 | 写完整的 `x = x + 1` |
| 三元 `? :` | 写完整的 `if` 与 `else`，或者把判断放进一个函数 |
| 区间 `0..10` | `for (i:int in 0 until 10)` |
| 科学计数法 `1e9` | `1_000_000_000.0` |
| 八进制 `0644` | 不支持，当场报错。需要这个数值就写 `644`，需要十六进制就写 `0x284` |
| `list<int> as object` 把容器装箱 | 装箱只接受 `class`、`struct` 和值类型，整个容器无法装入，在检查阶段就会报错；需要混合存放就逐个装入 |
| 插值 `"共 {n} 件"` | 花括号连同里面的名称原样输出，不会被替换；需要拼接就写 `"共 " + number.to_string(n) + " 件"` |
| `as?` 安全拆箱 | 只有 `as`，拆错时抛出 10011 号错误，可以 `catch` |
| `finally` | 作用域结束时自动释放，抛出时同样释放 |
| `throws` 标注 | 签名上不写任何标注，需要接收错误时写 `try` |
| `import * as u` 给工程里的文件绑定一整块 | 工程里的文件使用具名导入，需要改名用 `as`；整块绑定名称只有在引入 `libs/` 里的包时才有：`import greet from "libs/greet"` |
| `export default` | 只有具名 `export` |
| `x in xs` 查询容器中是否存在某个值 | 写 `xs.contains(x)`；`in` 只出现在计数循环与容器遍历这两种写法里 |
| `let (a, b) = p` 解构赋值 | 一次绑定一个名称：`let a:int = p.x`、`let b:int = p.y` |
| `f(param_name = value)` 命名实参 | 实参一律按位置传递，顺序就是声明中书写的顺序 |
| `xs[0][0] = 7` 这种连着两级下标写入 | 先把内层容器绑定到一个名称上，再修改绑定后的名称：`let row:list<int> = xs[0]` 之后 `row[0] = 7` |
| `struct Pair<T>` | 泛型只用于三个内建容器 |
| 匿名函数、把函数当值传递 | 没有函数类型。只能按函数名称调用，或者用 `switch` 分派 |
| 构造函数 `init` | `new C(field: value)` 就是给出初值的写法；`init` 这个名字没有特殊含义，写了也不会在 `new` 之后自动执行 |
| `->`、`::`、`@`、`#`、`...`、三引号字符串、模式匹配 | 都不是这门语言的记号 |
