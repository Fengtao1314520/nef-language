# 类型一览

每种类型都记录六项内容：大小、值域、字面量、默认值、可用运算和转换规则。

## 全部类型

| 类型 | 类别 | 大小 | 默认值 | 字面量 |
| --- | --- | --- | --- | --- |
| `boolean` | 值 | 1 字节 | `false` | `true`、`false` |
| `int` | 值 | 8 字节 | `0` | `42`、`-7`、`1_000_000`、`0xFF` |
| `float` | 值 | 8 字节 | `0.0` | `3.14`、`-0.5`、`1_000.25` |
| `byte` | 值 | 1 字节 | `0` | `200`、`0x1F` |
| `unicode` | 值 | 4 字节 | 码点 0 | `'中'`、`'a'`、`'\u4e2d'` |
| `string` | 引用 | 变长 | `null` | `"书包"`、`""` |
| `object` | 引用 | 变长 | `null` | 只能由 `x as object` 得到 |
| `list<T>` | 引用 | 变长 | `null` | `[1, 2]`、`[]` |
| `dict<K, V>` | 引用 | 变长 | `null` | `{"a": 1}`、`{}` |
| `hashset<T>` | 引用 | 变长 | `null` | `{1, 2}`、`{}` |
| `struct` | 值 | 8 字节的句柄；堆上的数据块等于各字段之和 | 逐字段默认值 | `Point { x: 1, y: 2 }` |
| `class` | 引用 | — | `null` | `new C()`、`new C(n: 1)` |
| `Calendar` | 值（内建 `struct`） | 8 字节的句柄；堆上的数据块 56 字节 | 七个字段都是 `0` | 只能由 `time.calendar(seconds)` 得到 |
| `enum` | 值 | 8 字节 | 见下文 | `D.a` |
| `Json` | 引用（内建） | 一个句柄；堆上每个节点各占一块 | `null` | 只能由 `json.parse(text)` 得到，解析失败时是 `null`（[解析 JSON](/stdlib/056_json)） |
| `bytes` | 引用（内建） | 一个句柄；堆上的数据块是“字节数 + 正文” | `null` | `bytes.new(4)`；`file.read_bytes(path)`、`s.to_bytes()` 也返回它（[字节块](/stdlib/047_bytes)） |
| `Socket` | 引用（内建句柄） | 操作系统分配的编号，不是堆上的一块内存 | `null`（未连接或者已关闭） | `net.connect(host, port, timeout_ms)`、`listener.accept()`（[TCP 套接字](/stdlib/057_net)） |
| `Listener` | 引用（内建句柄） | 同上 | `null`（已关闭） | `net.listen(port)`（[TCP 套接字](/stdlib/057_net)） |
| `Process` | 引用（内建句柄） | 同上 | `null`（启动失败或者已经回收） | `process.start(command_line)`（[进程](/stdlib/053_process)） |
| `Response` | 值（内建 `struct`） | 8 字节的句柄；堆上的数据块 24 字节 | 三个字段都是默认值 | 只能由 `http.get`、`http.post` 得到（[HTTP 客户端](/stdlib/058_http)） |
| `null` | 特殊值 | — | — | `null` |

`type Name = T` 不在上面这张表里：它不是一种新类型，只是给表中已有的类型另起一个名称，展开后仍然是原来的类型（见[定义](/reference/040_definitions)）。

值类型不可为 `null`，引用类型可以。`struct` 属于值类型，但名称中保存的是 8 字节的句柄，字段数据在堆上；整份拷贝与逐字段判等的详细说明见[值与存放](/reference/038_memory)。

## int

范围是从 −9223372036854775808 到 9223372036854775807，有符号 64 位。

| 运算 | 规则 |
| --- | --- |
| `+ - *` | 结果超出范围时在运行时抛出错误（10021 号），不回绕 |
| `/` | 除法后向零截断：`7 / 2` 得 `3`，`-7 / 2` 得 `-3` |
| `%` | 符号跟随左侧操作数：`7 % -2` 得 `1`，`-7 % 2` 得 `-1`。除法与取余合起来永远满足 `(a / b) * b + a % b == a` |
| 除以 `0` | 在运行时抛出错误（10022 号），既不返回无穷，也不返回 `NaN` |
| `& \| ^ ~ << >>` | 位运算只开放给 `int` 和 `byte` |
| 移位量 | 只接受 `byte`，写成常量时可以省略。`int` 用 `0` 到 `63`、`byte` 用 `0` 到 `7`：写成常量时越界是编译错误，计算得到的值越界在运行时抛出 10021 号错误 |

字面量允许 `_` 分组和 `0x` 十六进制，没有二进制和八进制写法。字面量本身超出范围是编译错误。

```nf
console.print(7 / 2, 7 % 2)
console.print(-7 / 2, -7 % 2)
console.print(1 << 4, -16 >> 2)
```

```text
3 1
-3 -1
16 -4
```

## float

64 位 IEEE 754 双精度，完全沿用 IEEE 的语义：上溢得到无穷，下溢得到 `0`，`0.0 / 0.0` 得到 `NaN`，`NaN` 不等于自身，`NaN` 参与大小比较时结果一律为假。这些都不报错。

| 事项 | 规则 |
| --- | --- |
| 字面量 | 只有“数字 `.` 数字”一种，没有科学计数法。`1e9` 会被读成数字 `1` 紧跟一个名称 `e9`，编译报错 |
| 大数 | 完整写出并用 `_` 分组：`1_000_000_000.0` |
| `%` | 按取余计算，符号跟随左侧操作数：`7.5 % 2.0` 得 `1.5`。两侧类型必须一致 |
| 除以 `0.0` | 不抛出，按 IEEE 得到 `NaN` 或者无穷 |
| 打印 | 采用最短往返写法，始终带小数点：`3.0` 输出为 `3.0`，`0.1 + 0.2` 输出为 `0.30000000000000004` |

## byte

一个字节，值域 0 到 255，无符号。两个 `byte` 之间的算术和位运算先按 `int` 计算，返回的是 `int`；比较运算仍然是 `byte` 对 `byte`，不支持取负（`byte` 没有负数范围）。移位量的类型正好是 `byte`：`byte` 作为左操作数时只能移动 `0` 到 `7` 位。

| 写法 | 结果 |
| --- | --- |
| `let b:byte = 200` | 合法：字面量出现在需要 `byte` 的位置上时按 `byte` 识别 |
| `let b:byte = 256` | 编译错误：`byte 只能装 0～255` |
| `let n:int = b + b` | 合法，结果为 `400`：运算结果是 `int`，可以容纳 |
| `let b2:byte = b + b` | 编译错误：`这里要的是 byte，给的是 int`，不会把 `400` 静默写入一个字节 |
| `let b:byte = n as byte`（`n` 是 `int`） | 值不在 0 到 255 内时，运行时抛出错误（10013 号，`超出了 byte 的值域`） |
| `300 as byte` | 编译错误：`byte 只能装 0～255，这里是 300`，字面量的值在编译期已经确定，不必等到运行期 |

`byte` 的 `++`、`--` 遵循同一条规则：`255` 再加一、`0` 再减一都抛出 10013 号错误，不会输出 `256`。

## unicode

一个 Unicode 码点，4 字节，排除代理区（`0xD800` 到 `0xDFFF`）。单引号内必须恰好一个码点，写入两个码点就是错误，写入代理区的码点同样是错误。码点之间按先后顺序比较。与 `int` 之间用 `as` 互相转换。

字符串和码点的字面量只支持五个转义：

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\"` | 一个双引号（写在双引号串里） |
| `\\` | 一个反斜杠 |
| `\uXXXX` | 码点为 `XXXX` 的字符，四位十六进制 |

写这五种之外的转义（`\z`）是编译错误，`\u` 后面不足四位或者不是十六进制同样是编译错误。文本中需要一个单引号时直接书写，不需要转义。没有 `\r` 这个转义形式：要判断回车就写 `"\u000D"`，或者用 `trim()` 把它当作空白去掉。

## string

引用类型，且不可变。

| 操作 | 写法 |
| --- | --- |
| 拼接 | `a + b`，生成一段新文本 |
| 判等 | `==`、`!=` 逐码点比较内容 |
| 比先后 | `<`、`<=`、`>`、`>=` 按码点先后顺序 |
| 取一个字符 | `s[i]` 返回一个 `unicode`，越界时在运行时抛出 10031 号错误 |
| 计算长度 | `length(s)` 返回码点个数 |

`[0] = 'X'` 这种改写其中一个码点的写法是编译错误，长度也不能原地修改。文本在内存中按 UTF-8 字节存放，头部另外保存码点个数，所以 `length` 只是读取一个已保存的数字，`s[i]` 却要逐字节扫描。需要频繁随机访问字符时，先把文本转换为 `list<unicode>`。

跨类型的转换不使用 `as`：文本解析为数字使用 `text.to_int(s)` 或者 `text.to_float(s)`，数字转换为文本使用 `number.to_string(value)`。整组文本操作见[文本处理](/stdlib/046_text)。

## object、as、is

`object` 用于存放不同类型的值，可以装入 `class`、`struct` 与值类型；文本无法装箱，在检查阶段就会被拒绝。值类型装箱需要一次堆分配，所以装箱必须显式写 `x as object`，没有自动装箱。

整个容器无法装箱，已经装箱的值也不必再次装箱：这两种写法都在检查阶段报错，报错原文收录在[命令行工具](/tools/059_cli)“生成阶段的边界”一节的表里，这里不重复列出。

装箱是否属于交出，取决于装入的是哪一类值：引用类型装箱后原名称当场失效；值类型装入的本来就是一份拷贝，原名称可以继续使用。

| 事项 | 规则 |
| --- | --- |
| 取回值 | 只有 `o as T` 一种写法。类型不符时在运行时抛出错误（10011 号），可以 `catch`，没有失败时返回 `null` 的版本 |
| 拆箱之后 | 装箱值已经为空，再次读取得到 `null`。拆箱会接管值，原来的名称无法再交出这个值 |
| 两个装箱值判等 | 比较对象身份：同一个对象才算相等，分别装入 `42` 的两个装箱值不相等 |
| `is` | 只查询不取值，返回 `boolean`，不会抛出；不自动收窄类型，判断通过后仍要写出 `as` |
| `is` 左侧 | 必须是一个引用类型上的值：装箱值，或者引用类型的名称。值类型与文本不需要判断，写了是编译错误 |
| `is` 右侧 | 具名类型都可以：`class`、`struct`、基础类型、容器类型都算，`interface` 的名称不行。左侧不是装箱值时，右侧只能写与左侧相同的类型 |

装箱值不能存入容器，因此 `o is list<int>` 能通过检查，结果永远是假。

从容器中取出装箱值再拆箱时，`box[0] as T` 连写即可：下标取出这一步本身就已经把值交出。

这里禁止的是对借来的值拆箱：`for (o:object in box)` 交出的 `o` 是只读借用，没有所有权，无法拆箱。例子见[容器](/reference/037_containers)。

## 转换

`as` 是唯一的转换记号，转换方向都要显式写出：

| 转换 | 结果 |
| --- | --- |
| `float` → `int` | 向零截断：`3.9` 得 `3`，`-3.9` 得 `-3` |
| `int` → `float` | `2 as float` 得 `2.0` |
| `class`、`struct`、值类型 → `object` | 装箱。文本不使用 `as`；整个容器与已经装箱的值都在检查阶段报错 |
| `object` → 原来的类型 | 拆箱，类型不符时抛出 10011 号错误 |
| `int` → `byte` | `as byte`，值不在 0 到 255 内时抛出 10013 号错误 |

除此之外没有隐式转换：`int` 不会自动转换为 `float`，`byte` 不会自动转换为 `int`，数字不能作为真假值使用。声明时的类型标注一律不能省略：变量、字段、参数、返回值和 `const` 都要写。

## 未提供的写法

本节列出的写法都不提供：可选类型语法 `T?`、`void`、泛型的 `struct` 和方法、函数类型与匿名函数，以及从右侧的值推导类型。
