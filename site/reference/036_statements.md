# 语句与块

本页说明一条语句在哪里结束、名称在哪个作用域内有效、条件与循环有哪些写法、运算符的优先级。

## 一条语句到哪里结束

行尾就是一条语句的边界。分号可写可不写，同一行书写两条语句也合法。

文件的顶层就是程序开始执行的位置：没有 `main`，从第一行执行到最后一行。`method`、`struct`、`class`、`interface`、`enum` 这些定义不参与执行，被调用时才执行。

```nf
method twice(n:int):int { return n * 2 }

console.print(twice(3))       // 6
```

## 声明与赋值

| 写法 | 含义 |
| --- | --- |
| `let x:T = v` | 可以再次赋值的变量，函数体、块和文件顶层都能声明 |
| `const x:T = v` | 之后不可修改，再写 `x = ...` 是编译错误；只能与值类型搭配 |
| `x = v` | 赋值：值类型整份拷贝，引用类型交出 |
| `x++`、`x--` | 自增、自减，只能用于 `int`、`float`、`byte` |

| 规则 | 内容 |
| --- | --- |
| 类型标注 | 所有声明都必须写，省略是编译错误 |
| 复合赋值 | 没有 `+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`\|=`、`^=`、`<<=`、`>>=`，要写完整的 `total = total + 1` |
| 赋值的位置 | `=`、`++`、`--` 只能自成一条语句。`while ((n = f()) != 0)`、`let b:boolean = (a = 2)`、`f(i++)` 都是语法错误 |
| 可修改的层数 | 赋值与自增减只能修改一层：`xs[0] = 7`、`xs[0].n = 3`、`d["甲"].n = 4`、`b.kids[0] = 7` 都可以。路径中间还要先从容器读走一个位置的写法（`xs[0][0] = 7`、`a[0].v = 7`、`xs[0][0]++`）是编译错误，需要修改时先把刚读走的位置绑定到一个名称上 |
| `const` 的类型限制 | 值类型（`int`、`float`、`boolean`、`byte`、`unicode`、只包含值类型的 `struct`）。`const items:list<string>`、`const txt:string`、`const c:C` 是编译错误 |

为什么只能修改一层：按照[值与存放](/reference/038_memory)的规则，从容器中读走一个装着引用类型的元素之后，那个位置就变为空。

所以 `xs[0][0] = 7` 写入的是一份已经不属于 `xs` 的值，改不到原本要修改的数；`xs[0][0]++` 需要把同一条路径读两遍，第二遍拿到的是空句柄。这种写法在检查阶段就会被拒绝：

```nf-bad
let xs:list<list<int>> = [[1, 2]]
xs[0][0] = 7       // 报：中间那个位置读走就空了，改不到它的下一层：先给它绑一个名字
```

分成两步就可以了，取出的值从此由新绑定的名称持有：

```nf
let xs:list<list<int>> = [[1, 2]]
let row:list<int> = xs[0]
row[0] = 7
console.print(row[0])   // 7
```

为什么 `const` 只能与值类型搭配：引用类型一旦作为参数传出就交出，一个“不能修改的名称”指向一个已经不属于本地的值，这样搭配不成立；而且名称不能修改、内容却可以修改，这样的“常量”本身就矛盾。

## 块与作用域

`{ }` 是一个作用域，块中声明的名称在离开块时失效。块内不允许与外层已有的名称重名：

```nf-bad
let x:int = 1

if (x > 0) {
    let x:int = 2      // 报：x 与外层的名字重名：不做内层顶掉外层
}
```

语言不提供“内层覆盖外层”。这条规则针对的是“以为修改的是外层变量”这类错误，代价是长函数中的中间变量需要各自有意义的名称。

文件顶层也是一个作用域：`let`、`const` 都可以写在顶层，顶层声明的值按声明的反序释放。顶层的名称会先收集完整，因此函数可以使用后面才声明的顶层变量。

顶层只有一处特殊：顶层声明的值要到整个程序执行结束才释放，而不是本文件执行到最后一行。原因与各文件的执行次序见[值与存放](/reference/038_memory)，跨文件的执行过程见[多个文件](/reference/042_modules)。

## 条件与循环

| 写法 | 规则 |
| --- | --- |
| `if` / `else if` / `else` | 条件位置只接受 `boolean`。没有三元表达式 |
| `while (条件) { }` | 先判断条件，再执行循环体 |
| `for (i:int in 0 until 10) { }` | 计数循环：从 `0` 到 `9`，一共十次，右端不包含。没有包含右端的写法，也没有 `..` |
| `for (v:T in xs) { }` | 遍历：`list` 交出元素、`dict` 交出键、`hashset` 交出成员、`string` 交出码点。交出的是只读借用 |
| `break`、`continue` | 只对最内层循环生效 |

## switch

可以作为判定对象的类型有六种：`enum`、`int`、`byte`、`unicode`、`boolean`、`string`。

| 规则 | 内容 |
| --- | --- |
| 标签 | 必须是常量或者 `const` 的值：数字、`enum` 成员、`true` 与 `false`、带负号的数。变量不支持，`null` 也不支持（能判定的六种类型都取不到它），区间（`0` 到 `10`）同样不支持 |
| 贯穿 | 没有。分支执行完不会继续执行下一个分支，不需要书写跳出语句 |
| 并列标签 | 一个分支可以书写多个标签：`Day.mon, Day.tue { }` |
| 重复 | 同一个标签写两遍是编译错误 |
| `enum` | 成员必须列全，漏掉一个又没写 `default` 是编译错误 |
| `boolean` | 列全 `true`、`false` 之后再写一个执行不到的 `default` 是编译错误 |
| 视为正常结束 | 分支在每条路径上都 `return`，加上标签已列全，函数就不必再写 `default` 或者函数末尾的 `return` |

## 运算顺序

优先级从高到低的表列在[语法速查](/reference/034_syntax)，供写代码时随时查阅。同一档优先级相同，一律从左向右结合。这里只列三条容易写错的规则：

`as` 是一个完整的后缀，需要访问成员时先加括号：`(o as C).x`。`&&`、`\|\|` 短路，左侧确定结果时不再计算右侧。`=` 不是运算符，它是语句，不参与任何顺序。

不确定优先级时加括号。

## 标点

| 记号 | 用处 |
| --- | --- |
| `:` | 类型标注（`let n:int`、`method f(v:int)`、`:int` 返回值），`dict` 字面量里的 `{"k": 1}` |
| `.` | 访问字段、调用方法、访问枚举成员 |
| `[]` | 下标读写：`a[0]`、`d["k"] = 5` |
| `<>` | 容器与泛型参数：`list<string>`、`dict<string, int>` |
| `( )` | 条件、参数表、调用、分组 |
| `{ }` | 语句块、四种定义的体内、两种容器的字面量、`struct` 字面量 |
| `,` | 参数、字段和字面量元素之间 |
| `;` | 可写可不写 |
