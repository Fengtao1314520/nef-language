# 容器

三种内建容器：`list`、`dict`、`hashset`。都是引用类型，长度都能变。

## 字面量

| 容器 | 有元素 | 为空 |
| --- | --- | --- |
| `list<T>` | `[1, 2, 2]` | `let a:list<int> = []` |
| `dict<K, V>` | `{"a": 1, "b": 2}` | `let d:dict<string, int> = {}` |
| `hashset<T>` | `{1, 2, 3}` | `let s:hashset<int> = {}` |

元素类型写在尖括号里。空的 `{}` 是 `dict` 还是 `hashset`，由左侧的类型标注决定，没有专门区分两者的记号。

`list` 与 `dict` 用方括号读写：`a[0]`、`d["k"] = 5`。`hashset` 不支持方括号，查询元素是否存在就写 `s.contains(v)`。

`hashset` 提供的动作是 `add`、`remove`、`contains`，另外还有并集、交集、差集三个方法（`union`、`intersect`、`difference`，各返回一个新的容器）。

容器可以作为 `struct` 与 `class` 的字段，可以作为参数和返回值，也可以互相嵌套：`let rows:list<dict<string, int>> = []`。在类型位置上连写的 `>>` 读作两个尖括号各自闭合，中间不需要加空格（`>>` 只有在表达式中才是右移运算符）。

元素类型只能写具名类型：值类型、`struct`、`class`、基础类型、另一个容器都可以；`interface` 的名称不行。需要混合存放就写 `list<object>`，取出后再用 `as` 拆箱。

存入引用类型时，**写入字面量的那个位置就是它的新持有者**：`let cs:list<C> = [c]` 之后 `c` 不再是持有者，`[c, c]` 是编译错误。字面量写入与 `cs.add(c)` 遵循同一套规则（[值与存放](/reference/038_memory)）。存入值类型本来就是整份拷贝，`[p, p]` 可以照常书写。

连着两级下标写入是另一回事：`xs[0][0] = 7`、`a[0].v = 7` 这样路径中间还要读走一个位置的，检查阶段就会拒绝，需要修改时先把刚读走的位置绑定到一个名称上（见[语句与块](/reference/036_statements)的“声明与赋值”一节）。

## 动作

这三个容器各有哪些动作，逐条列在[列表·字典·集合](/stdlib/049_containers)的成员表里，本页不重复列出。动作包括添加、删除、统计长度、查询是否存在、排序、查找位置、取出全部键与全部值、按位置插入与移除、颠倒顺序、追加另一个容器、截取片段、去重。

下面这些规则需要单独说明：

| 条目 | 规则 |
| --- | --- |
| 按键取值 | 只有 `dict` 支持（`d[k]`），`list` 与 `hashset` 都不支持 |
| 查询是否存在某个值 | `contains` 只有 `dict` 与 `hashset` 提供；`list` 写 `xs.index_of(v) >= 0`，或者自行遍历一遍 |
| 排序 | `sort` 只在 `list` 上提供，并且元素类型只能是可比较大小的五种：`int`、`float`、`byte`、`unicode`、`string` |
| 取首尾元素 | `first`、`last` 只有 `list` 提供，读法与 `xs[0]` 遵循同一条规则；容器为空时抛出 10031 号错误 |
| 全部清空 | `clear` 只有 `list` 提供 |
| 按键取值并可给出默认值 | `get` 只有 `dict` 提供：`d.get(k, fallback)`；键存在时的读法与 `d[k]` 相同，键不存在时返回该默认值，不抛出 10032 号错误 |
| 并集、交集、差集 | 只有 `hashset` 提供：`union`、`intersect`、`difference`，各返回一个新的容器，参与运算的两个容器本身不改变 |
| 按位置插入与移除 | 只有 `list` 提供：`insert_at(index, value)` 插入到该位置之前（位置等于长度时追加到末尾），`remove_at(index)` 交出该位置上的元素，后面的元素依次前移。位置不合法时抛出 10031 号错误，与方括号的规则相同 |
| 颠倒顺序、追加、取片段、去重 | 只有 `list` 提供：`reverse()` 就地颠倒顺序，`add_all(b)` 把另一个 `list` 的全部元素追加到末尾（被追加的容器不改变），`slice(start, end)` 返回一个新的容器（含起始位置、不含结束位置），`to_set()` 去重后返回一个 `hashset`。后三种方法要求元素类型能返回一份自身的拷贝，也就是值类型与文本；`class` 这类元素在编译期就会被拒绝 |

`length` 是函数不是属性，目的是让点号只表示一种含义：`a.x` 只表示字段访问，增删和长度都写成明确的函数调用。

`a.remove(9)` 删的是**等于 9 的那个元素**（文本按内容比较），不是下标为 9 的元素。要按位置删就写 `a.remove_at(9)`：它返回被删除的元素，同时把后面的元素都向前移动一个位置。

被删除的值当场释放：`d.remove("k")` 会连同该键对应记录里的值一起释放。`a.remove_at(9)` 返回的元素归接收它的名称持有，没有名称接收时在这一句结束时析构。

`add`、`remove`、`contains` 只是容器的方法，不占用全局名称：自定义的 `class` 中可以照常书写 `method add(...)`。

`dict` 的方括号分读取与写入两种情形：读取一个不存在的键抛出 10032 号错误；写入一个不存在的键就是新增一条记录，键已存在时是修改值。因此计数要先调用 `contains` 判断，再分支处理。

## 越界与缺键

| 情况 | 错误号 | 表现 |
| --- | --- | --- |
| 下标越界（容器与文本遵循同一条规则） | 10031 | 在运行时抛出，可以被 `catch` |
| `dict` 读取不存在的键 | 10032 | 在运行时抛出，可以被 `catch` |
| 遍历过程中修改这个容器 | 10033 | 在运行时抛出，可以被 `catch` |

不会返回零值，也不会返回 `null`。

## 元素的进出

| 元素类型 | 进出容器时 |
| --- | --- |
| 值类型（`int`、`float`、`boolean`、`byte`、`unicode`、`struct`、`enum`） | 拷贝，容器中的位置始终有值 |
| 引用类型（`class`、`string`、`object`、其他容器） | 交出，不论是进入还是取出，每个位置只保存一份 |

被读走的位置此后返回 `null`。

`let x:string = args[0]` 之后，`args[0]` 就是 `null`，需要判断就写 `if (args[0] != null)`；遍历读到的借用可能是 `null`，使用之前需要先判断。

一个位置只保存一份值，不会同时存在两份。存入 `class` 对象同理：`let c:C = cs[0]` 之后 `cs[0]` 是 `null`。

从容器中取出 `object` 再拆箱时，写成两步最容易看清：

```nf
struct Size {
    w:int
    h:int
}

let box:list<object> = []
box.add(Size { w: 2, h: 3 } as object)

let own:object = box[0]          // 先交出出来，那个位置空出来
let one:Size = own as Size       // 再拆盒
console.print(one.w * one.h)     // 6
```

`box[0] as Size` 连写也能通过检查：下标取出这一步本身就会交出值，两步合成一句即可。

## 遍历

| 容器 | 交出的值 |
| --- | --- |
| `list` | 元素，按顺序 |
| `hashset` | 成员 |
| `dict` | 只交出键，需要值时在循环内用 `d[k]` 取 |
| `string` | 码点 |

交出的都是只读借用：可以读取，也可以调用方法，但不能交出所有权，本轮迭代结束后就失效，遍历结束后容器仍然是完整的。元素是值类型时本来就是拷贝。

循环变量标注的类型必须与表中该容器交出的值一致：`list<T>` 与 `hashset<T>` 是 `T`，`dict<K,V>` 是 `K`，`string` 是 `unicode`。写成别的类型是编译错误，报出的仍是“类型之间不自动转换”。

计数循环 `for (i:int in 0 until n)` 交出的是 `int`，遵循同一条规则。

`dict` 和 `hashset` 的遍历不保证任何顺序。需要固定顺序时，另用一个 `list` 保存这些键。

```nf
let scores:dict<string, int> = {"甲": 90}
scores.add("乙", 71)

for (k:string in scores) {
    console.print(k, scores[k])
}
```

遍历过程中对被遍历的容器执行 `add`、`remove`、`sort`，会在运行时抛出 10033 号错误。需要修改时，先把键复制一份出来，遍历结束后再按这些键修改。

## 哪些值可以当键

| 可以 | 不可以 |
| --- | --- |
| `boolean`、`int`、`byte`、`unicode`、`string`、`enum`、`class`、`object` | `float`、`struct`、一切容器 |

`float` 不能作为键，因为 `NaN` 不等于自身，这样的键永远查询不到。`struct` 和容器不能作为键，因为比较内容需要逐字段进行，而字段还可以修改，散列值无法保持稳定。用不允许的类型作为键是编译错误，`hashset` 的成员类型遵循同一条规则。

`class` 与 `object` 作为键时按对象身份判等：同一个对象才算同一个键。分别装入 `42` 的两个装箱值不相等。

## 标准库如何接收容器

| 位置 | 语义 |
| --- | --- |
| 被操作的对象（点号左边的容器，或者内建组的第一个参数） | 只读借用，调用结束后持有者不变 |
| 传入的值（`box.add(c)` 中的 `c`） | 值类型拷贝，引用类型交出 |
