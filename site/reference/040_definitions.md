# 定义

`struct`、`class`、`interface`、`enum` 四种定义都写在文件顶层，不能嵌在 `struct` 与 `class` 的体内。

顶层还有第五种写法：`type Name = T`。它不定义新类型，只是给一个已有的类型另起一个名字，见[类型别名](#类型别名)一节。

## 对照

| | `struct` | `class` | `interface` | `enum` |
| --- | --- | --- | --- | --- |
| 类别 | 值类型 | 引用类型 | 编译期的约束 | 值类型 |
| 体内 | 只写字段 | 字段和方法 | 字段和方法声明 | 成员 |
| 构造值 | `Point { x: 1, y: 2 }` | `new C()`、`new C(n: 1)` | 不能直接构造 | `D.a` |
| 判等 | 逐字段比较 | 比较是不是同一个对象 | — | 比较整数 |
| 继承 | 只能 `base` 一个不带方法声明的接口 | 只能 `base` 一个接口 | 可以 `base` 另一个接口 | 无 |
| 能否有方法 | 不能 | 能 | 只有声明，没有体 | 不能 |
| 能否用作类型标注 | 能 | 能 | 不能 | 能 |

## struct

定义一个类型有哪些字段。

- 值类型：宽度固定、赋值整份拷贝、判等逐字段比较。存放形状的完整说明（名称中是 8 字节的句柄、字段数据在堆上）见[值与存放](/reference/038_memory)。
- `==` 逐字段比较，每个字段都相等才算相等。
- 字段只能放值类型、`string` 与另一个 `struct`。`class` 名、`object`、`list`、`dict`、`hashset` 写在字段位置上，编译期就拒绝：`struct 的字段只能放值类型、string 或另一个 struct，这里是 Note`。`struct` 的赋值是整份拷贝，而这些类型在内存里就是一个句柄：拷贝完成后两个名称指向同一个对象，这个类型就不再是值类型了。
- 嵌套一个 `struct` 字段可以，拷贝时逐层展开：外层复制一份，内嵌的字段也另建一份，修改外层影响不到内层。
- 允许一个字段都没有，空的 `struct` 占 0 字节。
- 字面量必须把字段列全，顺序可以打乱；漏一个或者名称对不上是编译错误。
- 不能写方法，因此无法实现带方法声明的接口。

## class

定义一个类型有哪些字段和方法。体内字段和方法都能写，一个方法都不写也合法。

- 引用类型：`let c2:C = c1` 是交出，`c1` 此后失效。
- `==` 比较对象身份，不看字段内容。
- 方法名在一个 `class` 里唯一，不按参数类型或个数重载。
- 方法体内直接写字段名就能访问自己的字段，`this` 可写可不写，两种写法等价。
- 字段名、方法名和接口带入的名称必须互不相同：`x:int` 和 `method x()` 并存是编译错误。

## interface

- 接口体内字段和方法声明都能写。方法声明不写 `method`，只写签名：`add(v:float):float`。写上这个关键字就是编译错误。
- `base` 后面只跟一个 `interface`。`interface` 自身可以再 `base` 另一个接口，字段与方法声明一并继承过来。
- 继承下来的字段自动拥有，实现者体内不再重写。
- 声明的每个方法都必须写出实现，漏一个是编译错误；参数名、参数类型、参数个数、返回类型和参数前的 `ref` 这五项都要与声明完全一致。接口声明 `add(v:float):float`，实现写成 `add(value:float):float`，参数名与声明不一致，同样是编译错误。这样只看接口声明就能确定调用怎么写，不必查看实现。
- 接口名不能当类型写：变量、参数、返回值、容器元素的位置上只能出现 `struct`、`class` 和基础类型的名称。接口只在定义处起作用，运行时不需要判断对象属于哪个接口，因此每个堆上的对象不必额外携带类型标识。需要把一组实现同一接口的对象放在一起时，用 `list<object>` 存入，用 `is` 判断，用 `as` 取出。

## enum

```nf
enum D { a = 0, b, c }

console.print(D.c == D.b)   // false
```

- 成员值只允许整数。不写值时取上一个成员的值加一，默认从 `0` 开始。
- 存储宽度与 `int` 相同，8 字节，但不参与算术。枚举能做的只有这几件事：取成员、判等、作为 `switch` 的标签、作为 `dict` 的键、作为 `hashset` 的成员、配合 `const` 使用，以及用 `as int` 取出对应的整数。反方向 `int as D` 不支持。
- 成员要通过类型名访问（`D.b`），成员名不会进入外层作用域，因此不同枚举可以有同名成员。
- 同一个枚举里两个成员不允许取同一个整数，否则 `switch` 的标签与判等都会产生两种解释。
- 作为 `switch` 的判定对象时成员必须列全。

## 类型别名

```nf
type Names = list<string>

let xs:Names = ["甲"]
xs.add("乙")
console.print(xs[1], length(xs))   // 乙 2
```

代码里写的是 `Names`，检查器处理类型标注时把它替换成右边的类型。

之后的判等、交出、装箱和形状表都按替换后的类型处理。所以 `let ys:list<string> = xs` 与一开始就写 `list<string>` 完全等价。

- 别名能写的位置与完整类型名相同：变量、参数、返回值的标注，参数的默认值，字段，容器尖括号里，`as` 与 `is` 的右边，`base` 后面，构造值（`Row2 { x: 1 }`、`new Box2()`），取枚举成员（`Choice.b`）。
- 别名不带类型参数：`Names<int>` 是编译错误，`Names` 本身已经是一个完整的类型。需要更换元素类型时，再写一条别名。
- 别名是一个类型名，不是值：`console.print(Names)` 报 `Names 是类型名，不是值（list）`。
- 同一个名称在类型定义里只允许出现一次。与 `struct`、`class`、`interface`、`enum` 或另一条别名重名，报 `P 已经定义过了`。
- 相互引用成环时在定义处就报错：`type A = A`、`type A = B` 配 `type B = A` 都返回 `类型别名 A 绕回了自己`，与有没有代码用到它无关。
- `interface` 本来就不能当类型使用（见 interface 一节），指向接口的别名在定义处就被拒绝。
- `export type` 声明的别名可以让别的文件引入使用。引入的名称即使在别名右侧只用上一次，也算使用过，不会报“import 了却没用到”。
- 别名可以指向另一个别名，一路替换到底：`type K = string` 配 `type Names = list<K>` 就是 `list<string>`。

## 字段与初值

| 事项 | 规则 |
| --- | --- |
| 可见性 | 字段没有内外之分，定义了就能读能改，不设 `public` 与 `private`。跨文件的可见性靠 `export` 决定 |
| 自引用 | 字段不能引用自己所在的类型：`struct Node { next:Node }` 是编译错误，这样的定义无法确定宽度 |
| 构造函数 | 没有。`new C()` 之后所有字段一律取该类型的默认值（`0`、`0.0`、`false`、`null`）。`new C(r: 2.0)` 这种按名称给出初值的写法，字段较多时才有意义：**传入的是引用类型就当场交出**，原来的名称随之失效（与装入容器时遵循同一条规则）；传入值类型时是整份拷贝，原来的名称照常可以使用 |
| 初值写法 | 在括号里按名称给出：`new Circle(r: 2.0, name: "大圆")`。使用了这种形式就必须给齐所有字段 |
| 构造值写法 | `new` 只用在 `class` 上，`struct` 用字面量 |
| 判空 | 字段读出的默认值是 `null` 时，使用之前要先判断 |

```nf
class Circle {
    r:float
    name:string

    method area():float { return 3.14159 * r * r }
}

let a:Circle = new Circle()                       // r 是 0.0，name 是 null
let b:Circle = new Circle(r: 2.0, name: "大圆")

console.print(b.name, b.area())                   // 大圆 12.56636
```

## 未提供的写法

泛型的自定义类型和泛型方法（`struct Pair<T>`、`method f<T>(...)`）都不支持；需要把几个值成对放在一起，就定义一个 `struct`。只有三个内建容器带类型参数。

定义不能嵌在定义里，四种定义与 `type` 别名都写在文件顶层。接口里的方法声明不带函数体，也不带默认值。

字段与方法都属于 `class` 的实例，没有 `static` 一类的类级成员。枚举成员只写名称与一个可选的整数，枚举不能定义方法。字段就是字段，没有 `get` 与 `set` 这类属性访问器，读写都直接写字段名。
