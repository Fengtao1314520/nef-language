# 屏幕输出与输入

这一组叫 `console`，负责两件事：向屏幕输出内容、从键盘读取一行。向屏幕输出分成两个输出流：`console.print` 写标准输出，`console.print_error` 写标准错误，两者的输出格式完全相同。

| 写法 | 返回 | 抛出的错误码 | 说明 |
| --- | --- | --- | --- |
| `console.print(...values)` | 没有 | 不抛 | 可以传任意多个值，值之间输出一个空格，末尾输出换行。变长参数上没有声明类型，所以单个不带类型的 `null` 无法传入，在编译期就会报错，不是运行期错误。约定写在[函数与调用](/reference/039_functions) |
| `console.print_error(...values)` | 没有 | 不抛 | 输出格式与打印到标准输出时完全相同，只是写入标准错误。把标准输出重定向到文件时，提示与进度信息不会写进文件 |
| `console.read()` | `string` | 不抛 | 等待一行输入，返回的内容不含末尾的换行符；没有可读内容时，返回 `""`。一行最多读取 `65536` 字节，达到上限就停止，多出来的部分留在输入里，下一次调用继续读取 |

```nf
console.print("这一行进文件")
console.print_error("这一行只是给人看")
console.print_error(3, 1.5, "甲")
```

把标准输出重定向到文件，文件里只有第一行；后两行仍然显示在屏幕上。重定向只写入标准输出的内容，所以文件里看不到后两行。

程序自己未捕获的错误（报错原文 `出错了（10031）：下标越界`）写到标准输出，与 `console.print` 的输出写到同一个地方。

```nf
let name:string = "阿明"
let age:int = 31

console.print(name, age, 1.5, true)
console.print()
console.print("下一行")
```

```text
阿明 31 1.5 true

下一行
```

## 每个值打印成什么样

| 类型 | 打印方式 |
| --- | --- |
| `int` | `42`、`-7` |
| `byte` | 该数值的十进制写法 |
| `boolean` | `true`、`false` |
| `unicode` | 字符本身 |
| `float` | 最短的往返写法，永远带小数点 |
| `string` | 内容，不带引号 |
| `list` | 方括号，元素之间是一个逗号加一个空格：`[3, 1, 2]`；空列表输出 `[]` |
| `dict` | 花括号，每一项是 `键: 值`：`{"阿明": 31}`；空字典输出 `{}`；**键的先后不保证** |
| `hashset` | 花括号，只输出键：`{1, 2}`；空集合输出 `{}`；先后同样不保证 |
| `struct` | 与写字面量时相同的形状：`Point { x: 1, y: 2 }` |
| `class` | 形状相同，字段按登记的先后顺序排列：`Bag { name: "甲", count: 3 }` |
| `object` | 拆开输出，输出的是内部值本身的形状，不额外标注这是一个对象 |
| 空句柄 | `null`。传入时要写成带类型的空句柄（`let none:Bag = null`），因为 `console.print` 的参数没有声明类型 |

一个字段都没有的 `struct` 与 `class` 输出为 `Point { }`。
文本出现在容器里、或者出现在字段位置上时要带一对引号；否则空文本显示不出任何内容。
直接输出文本时不带引号，单个字符（`unicode`）出现在容器里或字段位置上也一律不带引号。

```nf
struct Point {
    x:int
    y:int
}

let nums:list<int> = [3, 1, 2]
let nested:list<list<int>> = [[1, 2], [3]]
let names:list<string> = ["阿明", "小满"]
let ages:dict<string, int> = {"阿明": 31}
let tags:hashset<int> = {7}
let empty:list<string> = []
let p:Point = Point { x: 1, y: 2 }
let box:object = p as object

console.print(nums, nested)
console.print(names, ages)
console.print(tags, empty)
console.print(p, box)
```

```text
[3, 1, 2] [[1, 2], [3]]
["阿明", "小满"] {"阿明": 31}
{7} []
Point { x: 1, y: 2 } Point { x: 1, y: 2 }
```

循环引用的数据也要能输出完整。
对象通过字段指回已经输出过的对象（两个类型互相引用就能构造出这种数据），展开就没有终点，此时被重复引用的对象输出 `...`。
输出形如 `Node { name: "起点", peers: [...] }`：后面确实还有内容，只是不再输出第二遍。

判断依据是“这一次输出里已经输出过哪个对象”，而不是内容是否相同：两个并列位置指向同一个对象时，两处都会输出完整。
除循环引用外还有一条深度限制：展开深度超过 32 层时，更深层的内容也输出 `...`，用来防止合法但深度很大的数据造成过长的输出行。
看到 `...` 就表示再往下要么是被重复引用的对象，要么是深度超限的内容，两种情况用的是同一个记号。

“最短往返”的意思是：把输出出来的那串字符再次读回去，得到的还是同一个数，不隐藏误差。所以 `3.0` 输出为 `3.0` 而不是 `3`，`0.1 + 0.2` 输出为 `0.30000000000000004`。

`0.30000000000000004` 看起来刺眼，但这个结果是对的：这个数本来就不是 `0.3`。需要整齐的输出时，先把值取整（`math.round` 返回 `int`，`math.floor` 与 `math.ceiling` 同样如此）再打印；只想截断小数位就写 `x as int`。

> **注意：** `dict` 与 `hashset` 的输出顺序与插入的先后无关：哈希表不记录插入顺序。要按顺序展示给人看，就自己按需要的顺序把要输出的内容拼接一遍，`text.join` 用的正是这种办法。


## 读一行

```nf
console.print("叫什么名字？")
let who:string = console.read()

console.print("你好，", who)
```

屏幕上先输出提问，然后停下来等待回车。

`console.read()` 返回的文本不含末尾的换行符。没有可读内容时就返回空串 `""`，不抛出错误，也不是 `null`。写读取循环时注意这一点：判断“是否读完”要和空串比较，和 `null` 比较永远不会成立。

## 写到别处

这一组只向标准输出写入。要写文件用 `file.write`（见[读写文件](/stdlib/050_file)）；要把一个值转换成文本、自己先存起来，用 `number.to_string`。

标准库里没有“写入字符串流”这一类中间对象。要拼接一大段文本，用 `+` 和 `text.join` 就够了。

## 练习

`console.print(1, 1.0, 'a', "a")` 输出几个字段？第三个和第四个值看起来相同，类型差别在哪里？
