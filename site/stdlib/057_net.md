# TCP 套接字

这一页讲 `net`：TCP 套接字，用来自己定义一套协议。要获取一个网页，先用 [HTTP 客户端](/stdlib/058_http)；只有对方使用的不是 HTTP 协议时，才用 `net` 自己编写协议。

`net` 直接调用 Windows 自带的系统组件 winsock，不依赖任何额外组件。产物拷贝到另一台 Windows 机器上仍然可以直接运行，与其他功能没有区别。

## 超时

这门语言没有线程，一次调用就会停在原地等待。所以 `net.connect` 接收一个毫秒数：等待超过这个时间就报错，而不是永远停在那里。

```nf
let sock:Socket = net.connect("127.0.0.1", 9000, 3000)
```

第三个参数是 3000 毫秒，覆盖连接、发送、接收三个阶段。有一处例外：域名解析这一步不接受这个超时值，因为系统的 `getaddrinfo` 没有可以设置超时的参数，解析耗时多久由系统解析器决定。写 IP 地址时没有这段解析开销。

## 成员

| 写法 | 返回 | 抛出的错误码 | 说明 |
| --- | --- | --- | --- |
| `net.connect(host, port, timeout_ms)` | `Socket` | 10101、10102、10103、10104 | 建立连接。地址参数可以写域名或 IP 地址。10101 表示连不上，10102 表示连接超时，10103 表示域名解析失败，10104 表示地址或端口不合法 |
| `net.listen(port)` | `Listener` | 10104 | 在本机监听端口，等待连接进来。端口已被占用时也是 10104 |
| `Listener.accept()` | `Socket` | 10105 | 等待并接受下一个连接，返回对应的套接字 |
| `Socket.send(data)` | `int` | 10105 | 把字节块发送出去，返回已发送的字节数 |
| `Socket.recv_into(buffer)` | `int` | 10102、10105 | 把接收到的字节填入传入的字节块，返回填入的字节数；返回 0 表示对方已关闭连接。等待超时抛 10102 号 |
| `Socket.close()`、`Listener.close()` | 没有 | 不抛 | 提前关闭。不主动调用，名字执行到尽头时也会关闭 |

表里列出的五个错误码是 10101 到 10105。winsock 返回的原始号码没有折进对照表时，这一组同样落 10100 这个默认码，消息里带上系统的原始号码。

发送与接收用的都是[字节块](/stdlib/047_bytes)：一次能收到多少字节不可预料，所以 `recv_into` 要求先传入一块存放用的字节块，接收到的字节写进这块字节块，再返回写入的字节数。每收到一段数据就新建一个容器的写法在这里不适用。

### 做客户端

```nf
let sock:Socket = net.connect("example.com", 80, 5000)
let ask:bytes = "GET / HTTP/1.0\u000D\u000A\u000D\u000A".to_bytes()
sock.send(ask)
let answer:bytes = bytes.new(1024)
let got:int = sock.recv_into(answer)
console.print(got, text.from_bytes(answer.slice(0, got)))
```

换行没有 `\r` 这个转义记号，只能写 `\u000D`：转义表很小，可以背下来，这是[文本处理](/stdlib/046_text)定下的取舍。

这里没有写 `close()`：这段代码执行完 `sock` 就不再使用，套接字随之关闭。要中途关闭，写一句 `sock.close()`。

### 做服务器

没有线程，所以一次只处理一个连接。

接受一个连接，收发几轮数据，关闭它，再接受下一个连接。

```nf
let door:Listener = net.listen(9000)
while (true) {
    let one:Socket = door.accept()
    let box:bytes = bytes.new(256)
    let n:int = one.recv_into(box)
    one.send(box.slice(0, n))
}
```

上面的示例反复执行“回复一句就关闭”这个循环。要按行处理或识别协议，靠的都是 `recv_into` 返回的字节数和 `slice`。

## 句柄由名字持有

`Socket` 与 `Listener` 这两种值装着操作系统给出的一个编号，不是内存里的一块空间。规则是“名字失效时自动关闭”，与其他值在作用域尽头释放是同一思路，因此不需要手动关闭。

关闭之后这个名字就成为空句柄，再拿它发送或接收会抛 10092 号（`对着空句柄取成员或调用方法`），而不是再次关闭系统资源。

这两类不能放进容器，也不能装箱。容器要能取出里面的内容再整体销毁，而一个套接字只能关闭一次：两个名字指向同一个套接字，就会关闭两次。

```nf-bad
let socks:list<Socket> = []
// 报：Socket 进不了 list：它是操作系统给的句柄，只待在名字、实参与返回值里
```

## 未提供的能力

- 没有 UDP，没有原始套接字：要发送广播、使用组播，这一组没有提供对应的能力。
- 服务器不并发：这门语言没有线程，接受一个连接之后要先处理完、关闭它，再接受下一个连接。
- 接收与发送都以 `bytes` 为单位，没有按行读写的封装：要逐行读写，需要自己在 `Socket.recv_into` 与 `Socket.send` 的基础上编写。
